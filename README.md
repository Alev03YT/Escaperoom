# Archivio 47 — Escape Room

Prototipo web/PWA di una escape room narrativa interattiva, progettato principalmente per smartphone.

## Funzioni

- Timer da 15 minuti
- Cinque punti interattivi nella stanza
- Inventario degli oggetti
- Enigmi concatenati
- Tre indizi
- Salvataggio automatico della partita nel browser
- Schermata finale con statistiche
- Layout responsive
- Manifest per installazione come web app
